# Аварско-русский словарь Л. И. Жиркова, 1936

Москва: Государственный институт «Советская энциклопедия», ОГИЗ РСФСР.
Источник `av-ru.1936`, статус `test`; 7 027 статей в `data/av-ru.1936.jsonl`.

Файлы получены из предоставленной папки `new/`. С 30.10.2026 единственный
рабочий текстовый слой — структурированный HTML; JSONL собирается из него.
DOCX сохранён как архивный снимок прежней вычитки: в сборке не участвует,
дальнейшие изменения с ним не синхронизируются. PDF неизменен и используется
для сверки спорных чтений. Предисловие, грамматика и список опечаток
сохранены в HTML и оригинальном PDF.

Воспроизведение структурного импорта: `python3 src/parse_zhirkov_1936.py`.
После начала ручной вычитки JSONL не перегенерировать без переноса правок
в источник: скрипт перезаписывает файл целиком.

В HTML словарная часть находится на сканах 7 и 10–142. Сканы 8–9 содержат
продолжение введения и исключены. Первый полужирный заголовок становится
`word` (первый вариант до запятой, без звёздочки грамматического класса).
Продолжения абзацев на границах колонок/страниц присоединяются к предыдущей
статье. Заголовки букв, фонетические подсказки в колонтитулах и типографские
сигнатуры исключаются. При вычитке исправлены заглавные слова и присоединены три ложные статьи,
оказавшиеся продолжениями примеров; порядок оригинала сохранён.

## Структура

- `forms`: заглавное слово, начальные варианты и формы из квадратных скобок,
  без дубликатов. Это не только plural: предисловие прямо упоминает также
  падежи. Непомеченным формам число и падеж не приписываются.
- `senses`: русские значения, разделённые точкой с запятой до первого примера;
  запятые внутри перевода сохраняются. Пояснения в отдельных скобках переносятся
  в `precomment` или `comment`, оставаясь при своём значении.
- `senses[].forms` + `labels`: отдельные группы явно помеченных грамматических
  форм без выдуманного перевода. `act` — эргативный, `pos`/`poss` — родительный,
  `dat` — дательный, `l` — местный, `al`/`all` — направительный,
  `el` — исходный падеж; цифры 1–5 — серии. `pl`, `m`, `f` — число и род.
  Помета наследуется следующими формами до новой явной пометы.
- Глагольные `pr`, `perf`, `fut`, `part`, `imp`, `neg`, `frequ`, `adv`/`ger`
  раскрываются в русские `labels`; отсутствующие парадигмы не достраиваются.
- Происхождение в `labels`: `a` — арабское, `p` — персидское, `r` — русское,
  `t` — тюркское (в книге также кумыкское), `i` — интернациональный термин.
  Изолированные OCR-глифы `а`, `р`, `т` в позиции пометы распознаются так же;
  буквы внутри слов не меняются.
- `see_also`: `см.` → `kind: "see"`, `ср.` и OCR `cp.` →
  `kind: "compare"`, `=`/`==` → `kind: "spelling"`. Грамматическая помета
  `frequ.` сохраняется отдельно и не подменяет тип ссылки. Цепочки
  `= y, см. z` разбираются на две ссылки. Отсылка при выражении получает
  `comment` с этим выражением, чтобы не приписывать связь всему заголовку.
  Равенство между латинской фразой и русским переводом остаётся примером;
  равенство внутри русского пояснения не создаёт навигационную ссылку.
- `examples`: латинская фраза → `av`, русский перевод → `ru`, локальные
  грамматические пометы → `labels`, пояснения → `comment`. Основной разделитель
  — точка с запятой вне скобок. При пропущенном разделителе пример выделяется
  только при переходе от русского к латинской фразе, связанной с заглавным
  словом, и обратно к русскому. Русский фрагмент после примера продолжает его
  перевод. Примеры относятся к ближайшему предшествующему значению.

## Ограничения и вычитка

Историческая латиница сохранена. Подтверждённые графические варианты OCR
унифицированы скриптом `src/normalize_zhirkov_1936.py`; ударения и неизвестные
диакритические знаки сохраняются. Политика и исправленная таблица соответствий:
[отчёт о транслитерации](../../transliteration-ambiguity-report.md).
Пометы `11`–`15` разобраны как локативы `l1`–`l5`; `l` в позиции происхождения
разобрана как `i` по уточнению пользователя. Падежные пометы внутри парадигм
остаются падежными. Пояснения и диалектные ограничения форм сохранены.
После этой итерации комментариев «Неразобранная форма» нет; это не означает
завершения вычитки OCR. Формы `da`: `dabi`, `dabal`, обе plural, подтверждены
пользователем как исправление опечатки наборщика.
Звёздочки родового признака объясняются в комментарии; родовые формы по ним
не генерируются. Скобки в заглавном слове раскрываются: полное написание
становится `word`, все комбинации включения/пропуска — `spelling_forms`
(текущее `word` первым) и начальные элементы `forms`. Например,
`ş(v)anţixx` → `şvanţixx` / `şanţixx`; `bar(a)jka(t)` даёт четыре варианта.
Необязательные части после дефиса раскрываются вместе с дефисом.
`Odeen (ODN)` разобрано как название `Odeen` и вариант-аббревиатура `ODN`.
Примеры, падежные формы и грамматические пометы в скобках не раскрываются.
HTML сохраняет исходное сокращённое написание; повреждённые скобки требуют
ручной сверки. `piruz(a)` восстановлено по подтверждению пользователя.
Ссылки на точное прежнее заглавное слово перенаправляются на новое `word`.

[Постатейный журнал структурирования](../../changelog/2026-10-27-av-ru.1936-structure.md)
содержит исходный текст и полученный JSON каждой статьи, а также список
неоднозначных мест. Тесты проверяют сохранение всех исходных слов, кроме
раскрываемых сокращений; повторения форм и ссылок при этом дедуплицируются.
Это проверка отсутствия потерь, а не подтверждение правильности OCR или
каждой семантической границы. Статус остаётся `test`. Сводный словарь `av-ru`
этот исторический источник автоматически не использует.

### Unicode и ударение (30.10.2026)

Аварские поля JSONL нормализуются проверенной таблицей алиасов и Unicode NFC;
русские переводы не затрагиваются. Для `x̨` и `x̵` односимвольных эквивалентов
Unicode нет: их диакритики являются частью буквы и не удаляются.
Ударение заглавного слова переносится в `stress`, а в `word` и совпадающих
элементах `forms` остаётся форма без ударения. Позиция `stress` считается
по Unicode-символам итогового `word` с 1, включая дефисы и некомпонуемые
диакритики: `x̨áze` → `x̨aze`, `stress: 3`. Статьи с разным ударением не сливаются.
Ударения самостоятельных `forms` переносятся в необязательное `form_stresses`
у статьи или значения: ключ — индекс соседнего `forms` с 0, значение — позиция
с 1. Пример: `{"2": 2, "4": 5}`. Совпавшие после очистки формы не сливаются.
Ударения примеров пока сохраняются в тексте. Ударения в исходном HTML сохранены.
