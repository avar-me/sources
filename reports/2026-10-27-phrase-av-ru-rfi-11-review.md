## Отклонено

### #3 — МАГӀУ БАХЪИЗЕ

- поле: `variants[0]`
- текст: «БАЗЕ»
- замечание: The variant 'БАЗЕ' is an OCR artifact or misplaced fragment completely unrelated to 'МАГӀУ БАХЪИЗЕ'.
- решение: В PDF явно напечатано «МАГӀУ БАХЪИЗЕ (или БАЗЕ)». БАЗЕ — сокращённая запись варианта МАГӀУ БАЗЕ с общим компонентом магӏу, а не посторонний фрагмент OCR. Удалять variants не требуется.
- PDF: 193.


### #5 — РУГЪНАЛ МАГӀ

- поле: `senses[0].literal`
- текст: «гвоздь раны»
- замечание: The Avar word магӀ means tear (плакать/слеза), whereas магӀрухъ or similar might relate to nails, so 'слеза раны' is the literal meaning.
- решение: Реквестер смешал магӏ («гвоздь; кол») и магӏу («слеза»). В av-ru.2006 у магӏ есть пример ругънал магӏ = корпия. PDF подтверждает «гвоздь раны»; исправлять literal нельзя.
- PDF: 279.

- замечание: The source example addresses Fatimat as 'ГӀатӏимат', but the Russian translation incorrectly renders the name as 'Патимат'.

### #2 — ГАЛИ ТӀАСАН БЕГЬИЗЕ

- поле: `examples[0].av`
- текст: «КӀолищ дуда гьаб кинабго квешаб ккараб ш. иналда тӏасан галиги бегьун, нилъерго къисмат цо гьабизе?»
- замечание: The example contains an OCR artifact 'ш. иналда' splitting the sentence incorrectly.
- решение: На скане щиналда одним словом. Убрать ложную точку и пробел, восстановив щ вместо ш.
- PDF: 59.

- `examples[0].av`: «КӀолищ дуда гьаб кинабго квешаб ккараб ш. иналда тӏасан галиги бегьун, нилъерго къисмат цо гьабизе?» → «КӀолищ дуда гьаб кинабго квешаб ккараб щиналда тӏасан галиги бегьун, нилъерго къисмат цо гьабизе?»

### #4 — РАКӀ БАТИЗАБИЗЕ

- поле: `phrase`
- текст: «РАКӀ БАТИЗАБИЗЕ»
- замечание: The example uses ракӏ батинабизе, matching the causative verb stem батинабизе rather than батизабизе.
- решение: Заголовок РАКӀ БАТИЗАБИЗЕ совпадает с PDF; av-ru.2006 подтверждает батизабизе. В печатной цитате действительно батинабизе — одной разницы недостаточно для переименования статьи. При этом в начале той же цитаты есть очевидный OCR-дефект Тьенив: PDF даёт Гьенив. Предлагается исправить только Тьенив → Гьенив, обе глагольные формы сохранить.
- PDF: 242.

- `examples[0].av`: «— Тьенив гьавуна, гӏуна, гӏадан лъугьанищали лъаларо, господин капитан,— ян махсароялдалъун жаваб кьезе жигар бахъана дица, дагьабниги гьесул ракӏ батинабизе бокьун.» → «— Гьенив гьавуна, гӏуна, гӏадан лъугьанищали лъаларо, господин капитан,— ян махсароялдалъун жаваб кьезе жигар бахъана дица, дагьабниги гьесул ракӏ батинабизе бокьун.»

### #6 — ТӀЕМЕТӀИ ДАЛИЗЕ БИЧЧАЗЕ

- поле: `examples[0].av`
- текст: «Бацӏидаги бихьинчиясдаги бихьулареб жо букӏу-нарин, тӏеметӏи дализе биччаге.»
- замечание: The headword uses the infinitive ending -зе (биччазе), while the example uses the imperative form -ге (биччаге), which is normal morphological variation for an example sentence.
- решение: Различие биччазе/биччаге нормально; сам реквестер это признаёт. В примере есть другой дефект: строковый перенос букӏу- / нарин. Соединить букӏунарин, заголовок и биччаге сохранить.
- PDF: 306.

- `examples[0].av`: «Бацӏидаги бихьинчиясдаги бихьулареб жо букӏу-нарин, тӏеметӏи дализе биччаге.» → «Бацӏидаги бихьинчиясдаги бихьулареб жо букӏунарин, тӏеметӏи дализе биччаге.»
