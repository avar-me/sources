# en-av: соглашение о заголовках

Проверка: `python3 scripts/en_av_validate.py data/en-av.jsonl`.
Это структурная проверка, не подтверждение качества всех переводов.

## Поле word

- Непустое английское слово, устойчивое сочетание или морфема.
- Все буквы — латинские по Unicode. Диакритика допустима: `café`, `attaché`, `vis-à-vis`.
- Unicode-нормализация — NFC.
- Между словами допустим один обычный пробел U+0020. По краям пробелов нет.
- Дефис — ASCII `-`, апостроф — ASCII `'`. Они допустимы в словах,
  притяжательных формах и морфемах: `mother-in-law`, `dog's`, `dogs'`, `over-`, `-ever`.
- Скобки с пояснениями, перечисления через `;`, табуляции, невидимые
  символы, случайная пунктуация и длинные тире в заголовках не допускаются.
- Пояснения остаются в `precomment`/`comment`, грамматическая помета —
  в `labels`. Английский `comment` получает `comment_lang: "en"`;
  аварский comment по умолчанию — `av`. Не смешивать языки в одном comment.
- При разделении многозначного русского исходника выбирать английские
  заголовки по значениям, а не копировать весь набор значений каждому синониму.

## Явные исключения

В валидаторе разрешены только полные строки:

- `etc.` — стандартное сокращение;
- `St. John's wort` — название растения;
- `1.5-ton truck` — числовое сочетание;
- `yes, sir` — устойчивое обращение с запятой.

Новое исключение должно быть обосновано конкретной лексической записью
и явно добавлено в `WORD_EXCEPTIONS`. Нельзя разрешать произвольную
пунктуацию во всех заголовках ради одного исключения.
