## hunspell-av-ru-2026-07-13-*.tsv

Результат прогона `hunspell` (словарь `ru_RU` из [LibreOffice dictionaries](https://github.com/LibreOffice/dictionaries))
по всем русским полям (`text`/`comment`/`example.ru`, кроме помеченных `comment_lang: "av"`)
в `data/av-ru.jsonl` — 67 412 полей, 4044 уникальных слова вне словаря hunspell.

После отсева служебных обрывков (сокращения вроде «т. е.»), эвристики на собственные имена
и известной региональной/специальной лексики (годекан, баранта, ритль, хурджун, тухум,
джамаат и т. п.) осталось:

- **`hunspell-av-ru-2026-07-13-candidates.tsv`** — 3782 уникальных слова-кандидата. Формат:
  `слово\tколичество вхождений\tподсказки hunspell\tдо 3 примеров контекста (статья:поле:текст)`.
- **`hunspell-av-ru-2026-07-13-high-confidence.tsv`** — подмножество из 1346 слов, где у hunspell
  есть ровно одна близкая подсказка (расстояние Левенштейна ≤2). Формат:
  `слово\tколичество\tлучшая подсказка\tрасстояние\tпримеры контекста`.

Уже разобрано и исправлено (см. `CHANGELOG.md`, коммит `9a41f72`): верхушка `high-confidence`
с count≥3 (~60 слов) — 8 кластеров опечаток, дефис в составных цветовых прилагательных,
12 статей со слитым аварским определением без `comment_lang`.

**Не разобрано**: count=2 (426 слов) и count=1 (3080 слов) из `high-confidence`, плюс весь
остаток `candidates` без единственной близкой подсказки (~2436 слов) — эти по большей части
либо редкая лексика, которую hunspell не знает, либо собственные имена, не пойманные эвристикой,
но среди них наверняка есть ещё опечатки. Разбор откладывался по объёму — при следующем заходе
логично начать с `count>=2` в `high-confidence` как более многообещающего слоя.
