- `багӏаргьинаб` text: красноватий → красноватый
- `багӏаризабизе` text: усилять → усиливать
- `багӏарчараб` пример: птнами → пятнами

### POS / форма

- `базине`: существительное → глагол/инфинитив; из text убрано «(по)драить»
- `бакъваяб`: существительное → прилагательное
- `бакънагъине`: прилагательное → глагол/инфинитив
- `бакътӏерхьул`: глагол/инфинитив → прилагательное
- `бакь`: прилагательное → существительное
- `барахщине`: существительное → глагол/инфинитив
- `бай`¹ (землевладелец): междометие → существительное
- `бади-кӏалдиса`: глагол/инфинитив → наречие

### Структура / смысл

- `багъизе`: убран label «противительный союз»; «о ветре, о волне» из text →
  comment; «о переграду» → «об преграду»
- `байбихьизе` s2: обрезанный хвост «или с неопределённое» убран из text;
  comment «местоимение» → «с неопределённой формой глагола»; двоеточие в
  примере убрано
- `балагьизабизе`: пунктуация в s0; грамматическое описание деепричастия из
  text → comment
- `багӏарикӏкӏбагӏаррикӏкӏ` → `багӏарикӏкӏ`: склейка разбита; вторая форма
  `багӏаррикӏкӏ` в forms; из text убран «кизиль»
- `бакӏ`¹: госты → гости; пример «местные падежи» перенесён в sense «место»
- `бакӏалъул`: оформлен как родительный от `бакӏ` (`genitivefrom` +
  `see_also` kind `from`, form родительный)
- `бакъва-гадай`: `text: "от"` → `masdarfrom: бакъва-гадазе` + see kind `from`
- `бакътӏерхьуда`: «на Востоке» → «на Западе» + `precomment` «'Б' прописная
  буква»; хвостовое двоеточие в примере убрано
- `багӏасдо`: дьягил → дягиль; comment рудник → дудник
- `базарган`: формы базаргаица/базаргаил → базарганица/базарганил

## Отклонено (false positive)

- `багь-багьараб` (`рагь-рагьарал`): классное согласование (р-), не опечатка б-
- `багьизе` (`рагьана` в «обувь прохудилась»): то же классное согласование
- `багьизабизе` «разъясняться→разъяснять»: в статье уже активное
  «разъяснять, разъяснить»
- `барантик` «круговое определение»: заимствование, text = русское название,
  реальная дефиниция в comment («разновидность тика») — норма
