# 2026-07-17 — av-ru: опечатки в ботанических глоссах

Найдены при сверке словаря с русско-аварским справочником растений
(`avar_plants.pdf`). Точечные правы русских глосс.

- `жанзабил`: имбир → имбирь
- `кӏалбухӏ`: дикая редка → дикая редька
- `гьургьур`: кулыбаба осенняя → кульбаба осенняя
- `цӏцӏелчӏахӏ`: гелега лекарственная → галега лекарственная
- `сенеро`: омега → омег (устар. название болиголова)
- `карзама`: слово-метка «ботаника» убрано из `text` → text «название съедобной
  травы», добавлен `label: ботаника`
- `хӏетӏебагӏар`: text «перец водяной; . с красной ногой» → text «перец водяной»,
  букв. перевод вынесен в `comment: "букв. с красной ногой"`
