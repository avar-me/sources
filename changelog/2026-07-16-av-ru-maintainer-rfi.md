### Числительные — comment (как в раунде RFI-13)

`анкьнусазарго`, `анкьнусго`, `анлъазарго`, `анлъго`, `анлънусазарго`:
«при конкретное (числительное) счёте и в качестве определение» →
«при конкретном счёте и в качестве определения».

### Фактические числа (анлъ = 6)

- `анлънусазарабго`: «все семьсот тысяч» → «все шестьсот тысяч»
- `анлънусабго`: два дубля («все шестьсот» / «все семьсот») слиты в один
  «все шестьсот» с примером (семьсот → шестьсот овец)

### POS / форма

- `авалияб`: существительное/мн → прилагательное/—
- `азине`: существительное/мн → глагол/инфинитив
- `азияв`: глагол/инфинитив → существительное
- `амручи`: глагол/инфинитив → существительное
- `ана`: местоимение → глагол
- `азербайжан`: числительное → прилагательное
- `асатӏинав`: форма мн → именительный (ед.)
- `аскарияб`: существительное → прилагательное
- `асхӏаб`: прилагательное → существительное
- `айго`: глагол/инфинитив → местоимение
- `азалалда`: глагол/инфинитив → существительное/местный; добавлен text
  «искони, извечно; в предвечности»

### pos «выражение» → существительное (для явных существительных)

`абицар`, `агроном`, `азархана`, `азнавур`, `айрипалан`, `алиментчи`,
`анжилар`, `анонимка`, `аптекарь`: pos → существительное, из labels убрано
«выражение» (устар./разг. сохранены). Системный артефакт pos «выражение»
(≈971 статья) в целом не трогали — только эти помеченные RFI.

## Отклонено (false positive)

### comment уже помечен `comment_lang: av`

Инструмент снова принял аварский comment за пропущенный русский:
`адрес`, `академия`, `аллея`, `аллитерация`, `алмас`, `ампер`, `амперметр`,
`ананас`, `ангар`, `ангина`, `аннотация`, `архипелаг`, `аспирин`, а также
comment-часть у `амнистия`, `анонимка`, `антифашист` (там починены только
сопутствующие реальные ошибки).

### Легитимные формо-/вариант-заглушки (пустые senses по замыслу)

Грамматические формы и варианты с `see_also`/`pluralfor`/`masdarfrom`, глосса
не нужна: `абахъ` (диал., см. квар), `абгал` (мн. от `огоб` «рожь», а не «тёти
по отцу» — RFI ошибся), `абгияли`, `абизаби` (масдар), `аби` (масдар),
`аваданлъизаби` (масдар), `авал-рохен` (см. авал-къоно), `агьали` (см. агьлу),
`адаб-хӏурматалда` (см. адабалда), `алгияли` (местоим., см. гьалгияли).

### Прочее

- `амахваяб`: text-повтор заголовка оставлен — слово = вариант междометия
  `амахвад` («да помрёт твой отец!», восторг/удивление); в примере оно
  намеренно без перевода (свойство этого восклицания). Не трогали.
