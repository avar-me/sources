## Опечатки и правки текста

- **001 — `-ада`**:
  - `comment`: «прибавляется к собственным именам женщин в качестве; обращения» → «прибавляется к собственным именам женщин в качестве обращения»;
  - в примерах `Патӏимат--ада`, `Саният--адаца` → `Патӏимат-ада`, `Саният-адаца`.
- **003 — `бакътӏерхьуда`**: `бакътӏерхьудаса бакътӏерхьуде щвезегӏан` → `бакъбаккудаса бакътӏерхьуде щвезегӏан`.
- **005 — `бетӏер`**: «не задирай нос тот час, как стал руководителем» → «не задирай нос тотчас, как стал руководителем».
- **009 — `буго`**: «они с нашего аула» → «они из нашего аула».
- **011 — `гваргъизе`**: «керосин всполыхнул огонь» → «вспыхнул огонь на керосине».
- **013 — `гӏакъуба`**: «да будет божье воздаяние за испытавшие муки» → «да будет божье воздаяние за испытанные муки».
- **014 — `квацӏи`**: `comment` → «количество травы или стеблей злаковых, которое можно охватить одной рукой при косьбе или жатве».
- **017 — `лълъар`**: `comment` «полый, для заполнения начинкой колбасы мясом» → «полый; используется для наполнения колбасы мясом».
- **019 — `паркъи`**: «исчезновение с поля зрения» → «исчезновение из поля зрения».
- **020 — `прораблъи`**: восстановлена запятая между «должность» и «специальность».
- **021 — `рагьумахӏу`**: «никуда ни ходил» → «никуда не ходил».
- **023 — `ратӏа`**: «рёбра, примыкающиеся к передней ноге» → «рёбра, примыкающие к передней ноге».
- **025 — `рукъ`**: «во дворе был сугроб с дому» → «во дворе был сугроб величиной с дом».
- **030 — `ургьиб`**: `ru` восстановлено как «понять, переварить что-либо; вникнуть во что-либо», дублированное «что-либо» удалено из `comment`.
- **031 — `хисда-хисда`**: «крест на крест» → «крест-накрест».
- **033 — `чӏвазе`**: «надгробную стеллу» → «надгробную стелу».
- **034 — `щуябго`**: «все пятеро учениц» → «все пять учениц».

## Структурные правки

- **002 — `-гури`**: `pos` «существительное» → «частица»; `form` «множественное число» → «—».
- **004 — `батрак`**: `pos` «прилагательное» → «существительное».
- **006 — `бижизе`**: первое значение «(вы)растить что-либо» → «расти, вырасти, произрастать».
- **007 — `бихьинчи`**: `pos/form` → «существительное / именительный».
- **008 — `бихьинчияб`**: `pos/form` → «прилагательное / —».
- **012 — `гьобо`**: разорванные `ru: "долго"` и `comment: "болтать"` объединены в `ru: "долго болтать"`.
- **015 — `къедалаб`**: первое значение сокращено с «задорный, задорный человек» до «задорный».
- **016 — `кьан`**: заголовочное значение оставлено как «пах» с меткой «не склоняется»; `pos/form` исправлены на «существительное / именительный». Переносное «верховодить, командовать» сохранено в соответствующем примере.
- **022 — `рагӏи` (омоним 1)**: оборванное «выдать дочь или сестру за» восстановлено до «выдать дочь или сестру за кого-либо»; в `comment` оставлено «при сватовстве».
- **024 — `ратӏа`**: `text` очищен до «передняя нога», пояснение «животного» перенесено в `comment`; в пословице восстановлена вторая половина «тебе не подарят и переднюю ногу».
- **026 — `рукӏкӏине`**: `pos/form` → «глагол / инфинитив».
- **027 — `рукӏун`**: `pos/form` → «существительное / именительный».
- **028 — `рущен`**: `pos/form` → «существительное / именительный»; склеенная форма `рущенрущнаца` исправлена на `рущнаца`.
- **029 — `сверизе`**: пример `дуниял сверизе` («путешествовать, странствовать по миру») перенесён из значения «кастрировать» в значение «бродить, шататься; гулять, прогуливаться».
