# ru-av: ручная вычитка примеров и комментариев

Изменено 17 статей.

## Структура

- `пятиться`: из второго значения удалены перевод `нахъе кӏанцӏун чӏезе`
  и пример `пятиться своими интересами`, попавшие из статьи `поступиться`.
- `сельдь`: склеенные подпункты выражения `как сельди в бочке` разделены
  на два примера с одинаковым `ru`; аварские пояснения в скобках вынесены
  в `comment`; исправлено `как селди` → `как сельди`.
- `хватить`: выражения `хватить лишнего`, `хватить через край`, `хватит!`
  и `с меня хватит!`, стоящие после ◊, вынесены из значения «поразить»
  в отдельный sense без `text`.

## Опечатки и пояснения

- `вздорить`: `изза` → `из-за`.
- `всхлипнуть`: незаконченный комментарий `однократный глагол к` дополнен
  названием целевой статьи `"всхлипывать"`.
- `вылиться`: в `precomment` второго значения запятая после `во что`
  заменена точкой с запятой.
- `двое`: `на своих (на) двоих` → `на своих двоих`.
- `надломить`: `загӏиплъиззабизе` → `загӏиплъизабизе`.
- `огрех`: `постоя нные` → `постоянные`.
- `стопа¹`: `по стопом` → `по стопам`, `к стопом` → `к стопам`.

## Язык комментариев

В статьях `алюминий`, `бериллий`, `вольфрам`, `гафний`, `серебро`,
`стронций` и `фосфор` русский комментарий `химия элемент…` заменён
аварским `химикияб элемент…`. Так как для ru-av аварский язык комментария
используется по умолчанию, поле `comment_lang: "ru"` удалено.
